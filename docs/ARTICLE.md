# Salesforce CDC Analytics Pipeline
This project extends the original transformation architecture upstream. Instead of Skytrax scraping, a local Salesforce simulator models Account, Contact, Opportunity and OpportunityLineItem. It emits replay-ordered INSERT/UPDATE/DELETE events. The CDC consumer writes Snappy Parquet to S3 Hive-style daily partitions and advances each object checkpoint only after the raw write succeeds. Snowflake RAW preserves event history; dbt staging and intermediate models resolve latest state; marts expose Account/Contact dimensions and an incremental Opportunity fact. The existing engineering patterns remain: Snowflake RBAC with Terraform, dbt Slim CI, defer/favor-state deployment, GitHub OIDC, S3 production manifests, CloudFront dbt docs, Astronomer/Cosmos orchestration and Elementary observability.
